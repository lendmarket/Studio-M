# Studio M 편집기 기능 반영 결정

- 기존 영상 편집 도구(TB Drama 데스크톱 편집기)를 사용자 입장에서 분석한 뒤, 편집·관리·배포에 필요한 기능을 골라 확정한 목록입니다.
- 표기: 그대로 = 참고 도구 방식 그대로 / 개선 = 바꿔서 반영 / 신규 = 참고 도구에 없는 기능
- 사전 제작(S1~S6) 설계는 [preproduction-design.md](preproduction-design.md), 진행 상황은 [HANDOFF.md](HANDOFF.md)
