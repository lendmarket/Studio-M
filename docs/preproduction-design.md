# Studio M 사전 제작 설계 (확정 기록)

- 목적: 확정된 스토리를 기반으로 캐릭터·소품·의상·장소·대사·씬 영상 프롬프트를 만들고, 통합 검수 후 단계별 AI로 생성해 Studio M 편집 프로젝트로 넘긴다. **내 PC 전용**, 이후 **자동화** 가능 구조.
- 참고: 기존 드라마 제작 도구 분석 — 겹치는 단계·흩어진 생성 방식은 과감히 정리
- 표기: ✅ 확정 / 🟡 기본값(변경 가능) / ⏳ 미정

---

## 0. 전체 구조

| 상태 | 항목 | 내용 |
|---|---|---|
| 🟡 | 단계 | S1 스토리 개발(대화) → S2 제작 바이블 → S3 대본·씬·컷 → S4 프롬프트 + 통합 검수 → S5 생성 → S6 프로젝트로 넘기기 |
| 🟡 | 생성 방식 | 일괄 생성 + 건별 재생성, 시작 전 예상 비용 합계 표시 |
| 🟡 | 저장 | 작품 폴더 + 단계별 JSON/MD 파일 (사람이 읽고, 자동화가 읽기 쉬움) |
| ⏳ | 텍스트 AI | 설정에서 단계별 지정 (S1 확정 시 기본값 결정) |
| ✅ | 작품 유형 | **단편 / 시리즈** 구분 |
| ✅ | 단편 → 시리즈 전환 | 가능 (단편 바이블 → 시리즈 바이블, 기존 작품 → EP01) |
| ✅ | 공용 라이브러리 | 둠 — 작품을 넘나들며 캐릭터·소품·장소·목소리 불러오기/저장 |

### TB Drama 대비 정리한 점
| TB Drama | Studio M |
|---|---|
| 스토리 입력 경로 4개(마법사, AI 전개, 대본 붙여넣기, 외부 대화) | S1 하나로 통일, 외부 대본은 S1 입력 소스로 |

| AI 키가 웹·앱 설정에 분산 | 설정 한 곳에서 단계별 AI 지정 |

## 2. 시리즈 바이블 ✅

- 포함: **캐릭터·의상·기준 시트 / 소품·장소 / 세계관·톤·화면비·그림체 / 목소리 설정**
- 요소별 관리 항목

| 항목 | 내용 |
|---|---|
| 상태 | 🔒 고정(모든 화 유지) / ✏️ 화별 변경 가능 / ➕ 추가(EPxx 신규) / ⏸ 퇴장 |
| 연결고리 | 등장 화 목록, 인물↔인물 관계, 인물↔소품·장소, 복선(심은 화 → 회수할 화) |
| 변경 이력 | 몇 화에서 무엇이 바뀌었는지 |
| 참조 규칙 | 고정은 자동 적용, 변경은 해당 화 값 우선, 연결고리는 S4 검수 기준 |

- 새 화 시작 시 이전 화 참조: ✅ **화별 확정 요약 + 미회수 복선 목록**

## 3. 단계별 세부 (진행 중)

### S1 스토리 개발 ✅

| 항목 | 확정 내용 |
|---|---|
| 진행 방식 | **단계형 + 자유 대화** — 로그라인 → 줄거리 → 화·씬 구성 순서, 단계마다 AI가 2~3안 제안, 단계 안에서는 자유롭게 대화하며 수정, 단계별로 「확정」 |
| 입력 자료 | 아이디어 메모 / 참고 자료 첨부(문서·이미지·링크) / 기존 대본 붙여넣기 / 채널 성과 데이터 |
| 텍스트 AI | **Gemini (API 키 / Vertex)** — 스토리 대화·통합 검수 기본 |
| 핵심 원칙 | 대화로 확정한 내용을 **항목별로 정형화(구조화된 값)** 해서, 다음 단계의 각 요소에 그 값이 그대로 넘어가 자동 세팅되게 함 |

#### S1 산출물 — 확정 스토리 (정형화 항목 → 넘어가는 곳)
| 그룹 | 항목 | 형식 | 넘어가는 곳 |
|---|---|---|---|
| 기본 | 제목, 로그라인, 줄거리(기·승·전·결) | 텍스트 | S3 대본 생성 기준, 업로드 정보 초안 |
| 형식 | 장르, 톤·분위기, 타깃 시청자, 길이(편/화당 초), 화면비 | 선택값 | S2 그림체·톤, S3 컷 수·길이 배분, S4 엔진 제약 검수, S6 편집 프로젝트 화면비 |
| 구성 | 화 목록(제목·요약), 화별 씬 개요(장소·시간대·등장 인물·핵심 사건) | 목록 | S2 장소·인물 추출, S3 씬 생성 |
| 연결 | 인물 목록·관계(인물↔인물), 복선 목록(심는 위치 → 회수 위치) | 목록 | S2 캐릭터·연결고리, S4 연속성 검수, 시리즈 story_arc |
| 근거 | 입력 자료 목록, 대화 기록, 확정 버전·일시 | 파일 | 추적용 (제작 기록) |

| **연출** | **연출 방향**: 편집 리듬(예: 2~3초마다 장면 변화), 주요 촬영 기법(슬로우모션, 핸드헬드, 돌리 인 등), 씬별 연출 포인트 | 선택값 + 메모 | S3 샷 분할·카메라, S4 연출 검수, S5 영상 프롬프트 |

- 「스토리 확정」 후에는 잠금. 다시 고치려면 「새 버전으로 수정」 → 바뀐 항목이 영향을 주는 뒤 단계에 「업데이트 필요」 표시
- 시리즈: 시리즈 바이블 + 이전 화 요약·미회수 복선이 대화에 자동 첨부
### S2 제작 바이블 ✅

| 항목 | 확정 내용 |
|---|---|
| 만드는 방식 | **AI(Gemini) 자동 추출 → 요소별 수정·승인**. 시리즈 바이블·라이브러리에 있는 요소는 자동 연결 |
| 캐릭터 항목 | **기본**(이름·역할·성별·나이·성격·관계) + **외형 고정 문구**(영어, 모든 프롬프트에 첨부) / **연기 톤 + 목소리**(역할 톤 영어, 영상 속 목소리 스타일, TTS 목소리·감정·속도) / **표정·포즈 시트**(기준 시트 앞·옆·뒤 + 주요 표정·포즈) |
| 의상·소품 | **중요한 것만 바이블에 등록**(반복 등장·이야기상 중요). 나머지는 S3 씬 단계에서 필요할 때 씬 요소로 만듦 |
| 소품·장소 | 반복 등장만 + 기준 이미지·묘사 문구 고정. 장소는 시간대·빛·색감까지 |
| 기준 시트 이미지 AI | **Gemini 이미지(나노바나나, Vertex/API)** + 직접 업로드 |

### 연속성·연출 장치 (S1~S5 공통) 🆕
영상 생성이 3~15초 단위라 컷 사이 연결성과 씬 내 통일성(의상·자세·위치 등)이 깨지기 쉬움 → 기본 장치로 해결. 연출(2~3초 장면 변화, 슬로우모션, 각종 촬영 기법)은 **S1 스토리 확정 때부터** 방향을 정하고 S3에서 샷 단위로 구체화. 세부 방식은 S3에서 확정.
### S3 대본·씬·컷 ✅

**구조: 화 → 씬 → 컷(생성 단위, 3~15초) → 샷(2~3초 장면 변화)**

| 항목 | 확정 내용 |
|---|---|
| 컷·샷 관계 | **혼합(엔진에 따라 자동)** — 기본은 한 컷 안에 여러 샷을 담는 **멀티샷 프롬프트**, 멀티샷을 못 하는 엔진이면 샷마다 따로 생성 후 S6에서 이어 붙임 |
| 연출 지정 | **촬영 기법 라이브러리 + AI 추천** — 샷 크기, 앵글, 카메라 무빙, 렌즈, 속도(슬로우모션·패스트), 전환. 자주 쓰는 조합은 프리셋 저장 |
| 연출 확정 범위(S1) | **작품 규칙**(평균 샷 길이, 선호·금지 기법) **+ 씬별 핵심 연출 포인트**. 샷 단위 세부는 S3에서 채움 |

**연속성 장치 (4종 모두 적용)**
| 장치 | 동작 |
|---|---|
| 컷별 상태 인계표 | 컷 끝의 의상·자세·위치·손에 든 소품·시선·감정을 기록 → 다음 컷 시작 상태로 자동 인계 |
| 끝 프레임 → 다음 컷 첫 프레임 | 이어지는 컷은 앞 컷 영상의 마지막 프레임을 시작 이미지(참고)로 사용 |
| 씬 마스터 이미지 + 배치도 | 씬마다 공간 전체 기준 이미지와 인물 위치(좌·우, 시선 방향)를 정해 모든 컷이 같은 공간·방향 유지 |
| 씬별 룩 고정 | 씬마다 조명·색감·날씨·시간대 문구를 고정해 모든 컷 프롬프트에 첨부 |

**컷 항목**: 컷 번호·길이 / 등장 요소(인물·의상·소품·장소) / 시작 상태(인계) / 샷 목록(샷마다: 길이, 화면 묘사, 동작, 샷 크기·앵글·무빙·렌즈·속도, 대사·화자) / 끝 상태 / 전환 / 씬 요소(바이블에 없는 일회성 소품·의상)
### S4 프롬프트 + 통합 검수 ✅

| 항목 | 확정 내용 |
|---|---|
| 프롬프트 생성 | S1~S3 값으로 이미지·영상·음성 프롬프트를 **일괄 생성**(외형 고정 문구, 씬 룩, 상태 인계, 샷 연출 자동 첨부) |
| 검수 항목 | **일관성**(바이블과 다른·빠진 외형·의상·소품·장소) / **연속성·연결**(상태 인계, 배치도·방향, 컷 사이 동작 연결, 시리즈 이전 화와 충돌) / **스토리·대사·연출**(대사 길이 vs 샷 길이, 확정 스토리·복선 반영, 연출 규칙 적용) / **엔진 적합성**(길이·비율·프롬프트 길이 제한, 멀티샷 가능 여부, 안전 정책 표현) |
| 문제 처리 | **AI가 수정안 제시 → 항목별 수락·거절·직접 수정**, 「모두 수락」 가능 |
| 통과 기준 | **오류 0건, 경고는 허용** → S5 진행 |
| 생성 후 검수 | **자동 실행** — 컷마다 시작·끝 프레임을 뽑아 의도·다음 컷 연결 확인 → 어긋난 컷에 「재생성 후보」 표시 + 고친 프롬프트 제안 (끝 프레임 인계와 연동) |
| 검수 AI | Gemini (S1과 동일, 설정에서 변경 가능) |
### S5 생성 ✅
- Google 연동 경로 ✅: **Gemini API 키 기본 + Vertex(서비스 계정 JSON) 선택 지원** — 텍스트·이미지·영상·TTS 공통
- 단가표는 설정에서 직접 수정 가능(가격 변동 대비)


| 항목 | 확정 내용 |
|---|---|
| 생성 방식 | 일괄 생성 + 건별 재생성 (순서: 기준 시트 → 씬 마스터 → 컷 시작 이미지 → 영상 → 음성) |
| 영상 AI | **Google Veo·Omni** (Gemini API 키 또는 Vertex). Google Flow는 API가 없어 직접 연동 불가 → Flow에서 만든 영상은 **직접 업로드**로 컷 버전에 추가 |
| 음성 AI | **타입캐스트 + Gemini TTS** (설정에서 연동, 인물별 지정) |
| 테이크 | **기본 1개 + 필요 시 재생성**, 모든 버전 보관 후 「사용」 선택 |
| 비용 관리 | **예상 비용 + 작품(화)별 예산 한도** — 일괄 생성 전 합계 표시, 한도 넘으면 멈추고 확인, 실제 사용액 기록 |

### S6 프로젝트로 넘기기 ✅

| 항목 | 확정 내용 |
|---|---|
| 넘기기 범위 | **러프컷 자동 조립** — 컷 순서대로 영상(V1)·대사 음성(A1) 배치, 대사로 자막 생성(자막 템플릿 적용), 컷 전환·멀티샷 분할 반영. BGM·효과음은 편집에서 |
| 다시 넘기기 | **바뀐 컷만 교체** — 자르기·효과·자막 등 편집 내용 유지, 길이가 달라지면 알림 |
| 업로드 정보 | **S1 확정 스토리로 초안 자동 생성**(제목·설명·해시태그·태그·AI 고지) → 편집 후 확정. 시리즈는 화 번호·시리즈 태그 자동 |
| 제작 기록 | **자동 기록 + zip 내보내기** — 단계별 산출물, 생성 이력(안 고른 버전 포함), 편집 내역 |
| 이후 연결 | 편집 → 내보내기 → 배포 이력(F8)·제작 상태(E6)·성과 분석(P10) |
