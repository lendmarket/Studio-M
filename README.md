<h1 align="center">Studio M</h1>
<p align="center">Windows용 영상 편집기 · 타임라인 편집 · 자동 업데이트</p>

## 설치 (지인 공유용)

1. [Releases](https://github.com/lendmarket/Studio-M/releases) 페이지에서 `StudioM-Setup-x.y.z.exe`를 내려받아 실행합니다.
2. 코드 서명이 없어서 처음 실행할 때 "Windows의 PC 보호" 창이 뜰 수 있습니다. **추가 정보 → 실행**을 누르면 설치됩니다.
3. 설치 후에는 앱을 켤 때마다 새 버전을 자동으로 확인합니다. 업데이트가 준비되면 오른쪽 아래에 **재시작하여 업데이트** 버튼이 나타납니다.

## 주요 기능

| 영역 | 기능 |
| --- | --- |
| 미디어 | 동영상, 사진, 음악 가져오기(버튼 또는 끌어 놓기), 썸네일, 오디오 파형 |
| 타임라인 | 메인 트랙(자석 정렬), 오버레이 영상 트랙, 텍스트 트랙, 오디오 트랙 / 드래그 이동, 트랙 간 이동, 양쪽 트리밍, 스냅, 확대/축소 / 트랙 잠금, 숨기기, 음소거 |
| 편집 | 분할(Ctrl+B), 왼쪽/오른쪽 삭제(Q/W), 복제, 복사/붙여넣기, 오디오 분리, 실행 취소/다시 실행 |
| 플레이어 | 실시간 미리보기, 화면에서 직접 이동, 크기 조절, 회전 / 화면 비율(16:9, 9:16, 1:1, 4:3, 3:4, 4:5, 21:9), 전체 화면 |
| 텍스트 | 10가지 스타일 프리셋, 글꼴, 크기, 색상, 외곽선, 배경 박스, 그림자, 자간, 줄 간격, 정렬 |
| 스티커 | 이모지 스티커 |
| 전환 | 디졸브, 밀기(좌/우/상/하) |
| 애니메이션 | 들어오기/나가기: 페이드, 슬라이드(4방향) |
| 필터, 조정 | 필터 14종(강도 조절), 밝기, 대비, 채도, 색조, 색온도, 틴트 |
| 오디오 | 볼륨(0~200%), 페이드 인/아웃, 음소거 |
| 속도 | 0.1x ~ 10x (음 높이 유지) |
| 내보내기 | MP4(H.264/AAC), 480p~4K, 24~60fps, 화질 3단계, 진행률 표시 |
| 프로젝트 | `.smproj` 저장/열기, 20초마다 자동 저장, 비정상 종료 시 복구 |

## 새 버전 배포 (업데이트 내보내기)

1. `package.json`의 `version`을 올립니다. (예: `0.1.0` → `0.2.0`)
2. 커밋 후 같은 버전의 태그를 push합니다.
   ```bash
   git tag v0.2.0
   git push origin main --tags
   ```
3. GitHub Actions(`Release (Windows)`)가 Windows 설치 파일을 빌드해서 Releases에 올립니다.
4. 지인들의 PC에 설치된 Studio M이 다음 실행 때 자동으로 업데이트를 받습니다.

## 개발

```bash
npm install
npm run build   # 화면(Vite) + Electron 메인 프로세스 빌드
npm start       # 빌드된 앱 실행
npm run dist    # Windows 설치 파일 만들기 (Windows에서 실행)
```

구조:
- `electron/`: 메인 프로세스(창, 파일 대화상자, FFmpeg 실행, 자동 업데이트, 로컬 미디어 스트리밍)
- `src/core/`: 프로젝트 데이터 모델, 색상, 애니메이션, 텍스트 렌더링, FFmpeg 필터 그래프 생성. 미리보기와 내보내기가 같은 수식을 써서 결과가 일치합니다.
- `src/engine/preview.ts`: 캔버스 합성 + 미디어 동기화 + Web Audio 미리보기 엔진
- `src/components/`: 상단 바, 왼쪽 패널, 플레이어, 속성 패널, 타임라인, 내보내기 창
